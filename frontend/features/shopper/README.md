# features/shopper

assistant UI). Empty in Phase 2.1 — only route/layout validation exists so
far (see `app/(shopper)/shopper/page.tsx`). Follow the structure
established in `features/auth/` when building this out: `api.ts` (typed
backend calls), `schemas.ts` (Zod), `hooks/` (TanStack Query hooks),
`components/` (feature-local UI).
